# Data build scripts

These turn the three provided Excel extracts into the tables the notebooks read. Run them once, from the repo root, whenever the source files or the extraction change. Every output is patient-level data and is gitignored.

```bash
uv run python scripts/01_extract_rules.py
uv run python scripts/02_merge_llm_extraction.py
uv run python scripts/03_build_raw_tables.py
uv run python scripts/04_build_single_sheet.py
```

| Script | Reads | Writes |
|---|---|---|
| `01_extract_rules.py` | `data/*_deidentified.xlsx` | `data/structured_extraction.xlsx`: rule-based (regex) reading of the notes: valve model, size, SAVR/TAVR, echo values, event keywords |
| `02_merge_llm_extraction.py` | `data/llm_json/N*.json`, the workbook above | adds the LLM reading and the rules vs LLM comparison sheets to the same workbook |
| `03_build_raw_tables.py` | all of the above | `data/raw_tables/*.parquet` and `data/raw_tables.xlsx`: 15 long-format tables with nothing decided yet. **This is what the notebooks start from.** |
| `04_build_single_sheet.py` | `data/raw_tables/` | `data/all_data_one_sheet.xlsx`: every record from every source in one long sheet, for browsing by hand |

`data/llm_json/` holds one JSON file per note, produced by a separate Claude extraction pass over `notes_deidentified.xlsx` with a fixed question schema. It is not regenerated by these scripts. If it is missing, ask whoever ran the pass for a copy.

Only step 03 is needed before the notebooks. Steps 01 and 02 must have run at least once because 03 reads their output.
